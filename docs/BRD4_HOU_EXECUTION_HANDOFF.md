- 受体：a1–a4 取 §7.10 的 MODELLER 模型（去掉 MODELLER 加的 OXT）；a5–a7 取原 PDB 的 L/H 链。PDBFixer 只补缺失的重原子（a5–a7 各 11–12 个残基的侧链；不补缺失残基、不加 OXT）。His 态用 `reduce -NOFLIP -HIS -NUClear`（与多肽 v2.1 同一调用）判定，之后去掉全部 H，由 tleap 重建。截断端加 ACE/NME（轻链两端、重链 C 端），重链 N 端 Ile16 保持带电。SSBOND 四对 → CYX + tleap 显式成键（S–S 1.95–2.08 Å）。
- 配体：键级、原子名和立体化学取 CCD（`sources/hou2011/ccd/*.cif`，2026-10-23 从 RCSB 下载），重原子坐标取晶体；pH 7.4 按 §7.1：a1–a4 两个吡咯烷 N +1（净 +2），a5/a7 脒 +1，a6 羧酸去质子（净 0）。AM1-BCC / GAFF2（antechamber + sqm），parmchk2 无 ATTN 项。
- **a6（1DWC）立体化学**：沉积坐标里 MIT 的 C2（哌啶 4-甲基所在碳）是 S，而 CCD 标注、CCD 理想坐标和模型坐标都是 R。按 §7.2 以 CCD 为准：把甲基 C10 以 C2–C3–C10 平面为镜面反射（位移 2.47 Å，其他原子不动），翻转后复核为 R。反射后的 C10 离受体重原子最近 2.66 Å，靠 setup 的无约束最小化放松。这是模型限制，记录在案。
- 晶体水和 Na⁺ 保留；与新建原子（loop、PDBFixer 补的原子、帽）的 O–重原子距离 < 2.6 Å 的晶体水去掉（2.6 Å 是 O···N/O 氢键距离 2.6–3.2 Å 的下限）。结果只有 a2 去掉了 B593（2.39 Å，与 §7.10 的预判一致）。
- 溶剂：ff14SB / GAFF2 / TIP3P（JC 离子），长方体盒、边距 12 Å，先中和，再按 n_salt = round(0.15 × N_wat / 55.5) 加 0.15 M NaCl。体系 38.8k–48.3k 原子。受体电荷：1D3* 为 +5，1DW* 为 +4（1DW* 的轻链多观测到 Glu1C）。溶质电荷偏离整数 ≤ 0.002 e（来自 AM1-BCC mol2 的四位小数）。
