## 1. 先解决什么

**当前瓶颈是实验样本与结构输入的对应关系。** 数据库有亲和力记录、某一系列带 PDB 编号，都不等于每个实验样本有自己的复合物结构。

This task uses published experimental measurements and existing PDB structures for retrospective MD / MM-PBSA analysis. Input sequences come from the published records.

不再扩充新的实验数据源。先把已有系列逐组审计；查询这些系列的原文和对应 PDB，是核实已有数据。暂缓完整数据包获取及尚未补齐的 2025 年筛选记录，沿用交接 §4.4。

## 3. 每个样本怎样获得可用结构

按结构证据分类，同时保留缺失残基和化学问题，不能只填“有 PDB / 无 PDB”。

| 类别 | 可用证据 | 拟用路线 | 报告边界 |
|---|---|---|---|
| A：对应实验复合物 | 序列、受体、位点能对应本样本 | 处理缺失原子/残基、替代构象、末端与必要小分子；保留实验坐标及处理记录 | 补建部分仍是模型；晶体条件不自动等于测定条件。 |
| B：同位点、相近骨架模板 | 已发表同家族复合物，可明确映射样本变化 | 共用明确的参考骨架，按各样本原始序列重建侧链/末端，单独参数化与采样 | 是模板模型，结合姿态继承自参考；不能称该样本的实验结构。 |
| C：需要明显骨架变化 | 长度、缺失环区、结合模式或位点对应不确定 | 暂离首轮；单独制定结构验证与采样方案，再决定纳入 | 不能把一次侧链替换加短最小化当成问题已解决。 |
| D：关键输入未闭合 | 末端、修饰、构建体、参数或位点未知 | 保留问题和出处，暂缓 | 不猜测化学形式、拼接结构或补造实验标签。 |

自由肽结构或单体预测结构不能直接替代复合物姿态。短 MD 通常也不能承担从未知起点找出正确结合姿态的任务；若没有合理复合物起点，先解决结构证据问题。

首轮主比较建议统一以 3EQS 参考骨架准备八样本，减少“每条选不同起点”带来的不均衡。若发现某样本有更直接的实验复合物，记录并用于结构敏感性对照；是否替换主协议起点，要在排名分析前确定。

### 3.2 正式准备前要落实的三个决定

1. **受体模型：** 原文构建体、链与残基范围；哪些缺失部分补建，哪些截短；所有样本使用怎样一致的受体模型。
2. **化学形式：** 每条肽和受体的末端、修饰、质子化与净电荷。以实验记录为依据，不能为了排名好看选自由末端或 ACE/NME。
3. **复合物状态：** 位点与链配对、必要辅因子/离子、重要水及结晶添加物。逐类说明保留或去除依据，不使用“全部去掉异质分子”作为通用规则。

未知处记录为 `pending`。若必须采用假设，说明证据缺口和敏感性检查；关键差异不能关闭时不进入正式实验比较。

## 5. 结构和轨迹怎样检查

### 5.1 准备结果

- **身份与化学：** 序列、残基数、原子完整性、键连接、末端、修饰、质子化、净电荷和受体/肽索引逐项匹配清单。
- **几何：** 碰撞、主链/侧链几何、肽键和局部构象异常；区分原始结构已有问题与补建引入的问题，记录处理前后变化。
- **位点与补建：** 受体对齐后检查肽位置、参考接触和补建区域。补建多个可行起点时，按固定几何规则处理，不按实验亲和力或最终 PBSA 分数选模型。
- **过程记录：** 原始文件、链/残基映射、删除及保留分子、准备工具/参数、随机种子、最小化与平衡日志；“最多 200 次”不是收敛证明。

硬性输入错误需要解决；构象偏离则先诊断，不能用“必须保持参考接触”作为筛掉弱样本的条件。具体几何检查规则在准备协议中固定，不能在看完排名后补阈值。

### 5.2 获准运行后的平衡与生产

在拟采用的溶液条件下进行最小化和平衡，约束及释放方式统一记录。区分仅去碰撞、受约束平衡和正式生产轨迹；比较阶段不保留人为维持实验结合姿态的约束。

记录能量/温度等过程诊断，以及受体对齐后的肽构象、位点接触、二级结构和补建区域变化。不把 RMSD 小当成亲和力准确，也不把短轨迹没有脱离位点当成实验强结合证据。

若出现解离、错误起点或持续数值异常，按预先规则记录并单独分析；不能强行拉回、删除不利帧或按标签重新挑起点。PBSA 的轨迹区间和帧筛选规则预先固定，相关不确定性保留。

模板模型得到的是条件于所用起点和采样范围的结果。若不同合理起点间差异大于样本间分差，先报告模型不确定性，不能将其解释为精细亲和力排序。

| 原文测量清单 | 论文身份、原始实验定位、化学样本身份、受体构建体、测定/条件、指标、规范单位值、误差定义、删失状态、核实状态 | 正式实验比较只引用核实后的原文点；同一样本可以有多种测量。 |
| 样本结构清单 | 原文样本 ID、准确序列/修饰/末端、PDB/链/残基映射、A–D 类、实验与补建区域、必要分子、力场/质子化/电荷、准备路线、待办和排除理由 | 连接实验记录与计算输入，支持逐样本检查。 |

论文别名统一与测量去重分开。去重核对的是**同一原始实验测量**，不能只用序列、DOI 或相同数值判断；同序列的不同修饰、构建体、条件或测定保留。来源未知时先列候选重复簇，不提前删原始行。

每个样本分别记录 `label_ready`、`structure_ready`、`parameter_ready` 和原因；进入正式计算需这三项的证据完整。文件生成成功或库内带 PDB 字段均不能代替这些状态。当前审计派生的 CSV 不自动升级为已验收输入。

### 8.2 协议需要固定的内容

`protocol.md` 在正式排名前写清：纳入/排除规则、首轮与保留划分、三个输入决定（§3.2）、准备工具及参数、独立初始化与随机种子、溶剂/离子、平衡与生产方案、约束释放、采样长度确定方式、取帧与失败处理、PBSA 参数/数值检查、主要统计终点、基线、成本口径。

方法和默认参数遵守项目冻结基线。数值收敛与工程错误可以诊断，不能利用验证标签调介电、半径、评分权重或结构选择来改善结果。记录任何协议修改及受影响的数据；修改后不能继续把已用于调参的数据称作独立验证。

当前已经接触 PMI 实验标签，后续同系列样本是协议保留验证，不称盲测。不同靶点和原始实验的独立性按实际来源检查。

### 8.3 后续实现任务

1. **准备入口：** 读取结构/化学清单，按路线生成逐样本输入；保存原子映射与处理记录，发现序列或参数不匹配就明确失败。
2. **作业入口：** 每个样本、初始模型、MD 副本独立身份与目录；真实随机种子、检查点、续跑与完成条件可追溯。
3. **分析入口：** 输出结构/采样诊断、逐帧分项与数值状态；按副本和时间块汇总，记录有效帧和失败。
4. **汇总入口：** 从固定清单生成分组排名、实验比较、对照与成本报告，保留全部纳入样本和失败记录。

这些是后续必要软件任务，不表示已实现或当前要求立即写代码。先审查现有入口，只补实际缺口；不为了本批工作改方法默认、生产环境或历史输出。

目录应区分 `inputs/`、`prepared/`、`md/<sample>/<model>/<replica>/`、`scores/`、`reports/`；将实际命令、运行环境和输入/产物映射写入记录。空目录、退出码为零或单个分数文件均不足以认定整项完成。恢复时核对检查点与原始输入、参数、原子顺序一致，不能给旧轨迹配上新拓扑。

## 9. 评分、对照和统计如何推进

### 9.1 顺序

先检查输入及轨迹，再做相同快照上的数值对照和收敛诊断，最后评价实验排序。若候选间分差小于数值或采样变化，先报告分辨率不足，不从相关系数反推数值参数。

参考实现与 JAXPBSA 对照时，共享坐标、原子划分、力场参数及匹配的 PB/非极性设置。分别比较 MM、PB、非极性项和总分，记录求解/边界失败。网格、边界余量和刚体平移/旋转敏感性按总纲检查；数值精度、物理模型和采样差异分别报告。

正式比较保留 MM/GBSA、CPU Amber MM/PBSA 参考、可取得的原文/结构评分，以及随机、长度/电荷/接触等诊断基线。缺失的原文评分如实标缺失，不补造或默认本方法已优于它。

### 9.2 统计口径

- 同靶点、同测定可比组内报告 Spearman/Kendall、成对次序及不确定性；Kd 与评分方向统一。
- Top-k/富集的强结合定义和 k 在正式分析前固定；标签不足时不强行报告分类结果。未测、未纯化和不确定拟合不是阴性。
- 误差以独立副本、适当时间块及实验误差为基础，轨迹帧不当独立样本；区分不同起点的模型变化与同起点的采样变化。
- 删失标签按原文检测信息处理，不补出一个人为 Kd；Ki、Kd、IC50 和不同测定不混合排名，跨靶点不合并原始能量分数。
- 报告所有预先纳入样本、失败、排除理由和覆盖偏差。不同肽长度/家族分别诊断，不只展示最容易恢复的热点破坏样本。

只有结合态端点评分时，不能将其称完整结合自由能。若长度、柔性或预组织差异导致结果难以解释，可安排游离肽系综诊断，但需另列预算；诊断不自动补齐熵和重组自由能，也不作为随意添加经验修正的理由。

## 10. 成本、资源与继续条件

### 10.1 资源计划

待用户后续指定运行安排后，按适用规则提交具体作业表：节点与真实连接身份、当前负载、CPU/GPU/线程、样本/模型/副本数量、命令、实测时间依据、可续跑性、输出目录、该批结果要决定什么。

目前没有可靠总耗时估计，不用旧 CPU 准备时间、同一构象重复评分或其他 GPU 的内核速度外推本批工作。获准后在目标资源测小批次成本，再估正式规模；未来作业避免争用本机已有任务。

### 10.2 成本要回答的问题

完整记录准备、平衡、生产 MD、编译/定尺、评分、统计、I/O 和失败重试；分别给出墙钟时间、CPU/GPU 用量及峰值内存，必要时单列排队等待。性能对照同时说明硬件与完成的实际工作量。

评价“更划算”时统一总预算或统一筛选目标，观察预算增加时的排序稳定性和实验高亲和力样本保留情况。实验名额节省只是回顾性估计，不写成已节省真实湿实验天数。在线异步与早停放在固定预算工作流已有证据之后；早停要独立评价误淘汰，不能看到早期分数差就停样本。

### 10.3 结果对应的下一步

| 观察 | 下一步 |
|---|---|
| 原文标签、受体或化学对应不了 | 暂缓该样本/组，记录原因；在现有清单内选择可闭合的案例。 |
| 补建或不同合理起点影响很大 | 先诊断结构不确定性；暂不做精细排序主张，不拿统一短 MD 掩盖起点问题。 |
| 数值误差影响次序 | 做匹配参考与数值收敛排查；冻结后重新分析，避免按实验标签调物理模型。 |
| 副本/时间块变化影响次序 | 根据固定诊断和获准预算调整采样，或报告不可区分；不能只重复评分来缩小误差。 |
| 只区分明显弱样本，合理样本间分不开 | 报告粗粒度用途和分辨率限制，不宣称精细亲和力预测。 |
| 首轮有效、保留集或不同靶点无增益 | 收窄适用范围，公开失败；不得反复调验证集后继续称独立验证。 |
| PBSA 部分快，但总成本仍由 MD 主导 | 分开报告内核收益和全流程成本，不推导整体筛选提速。 |
| 排名无增益，但数值与性能证据成立 | 保留软件分析结果，收窄应用主张；不隐去负结果。 |

具体验收容差由诊断依据和总纲要求在正式比较前记录。没有证据时不凭空设阈值，也不因预算耗尽把未完成项目写成完成。
