## 3. 把“结构不对”分成四种情况

| 情况 | 要核对的证据 | 后续处理 |
|---|---|---|
| 序列/原子映射/坐标展示问题 | 样本身份、链和编号、拓扑–坐标顺序、Å/nm、周期成像、受体对齐、模型版本 | 先修数据对应或展示/分析；再判断真实计算输入是否受影响 |
| 构建或准备引入的硬错误 | 错序列、错误连接、非预期手性、HA方向、严重冲突、局部键角、端基和参数 | 定位第一次出现的阶段，修该阶段；重做受影响的下游 |
| 模板模型的结合姿态缺少支持 | 变体对应的实验结构、模板可迁移范围、骨架/侧链适配、不同合理起点 | 明确模型假设；必要时补有限结构对照或重新选择结构证据更齐的系列 |
| 几何合理但 MD 中发生构象变化 | 正确成像后、受体对齐下的核心接触/二级结构/端部运动，起点与副本依赖 | 按结构与采样不确定性分析；不自动拉回晶体或删除不利副本 |

优先排查坐标表示：`scripts/strip_peptide_replica.py` 从原始轨迹计算受体对齐后的 diagnostics，之后才对干轨迹做 `image_molecules`。这段执行顺序已核实；是否造成某条诊断或可视化异常仍待对照原坐标，当前不作为已确认 bug。

每个问题记录：样本/model/replica、源文件与阶段、受体/肽残基和原子、看到的现象、是否完成周期成像和受体对齐、比较参考是什么、最早出现在哪一阶段。没有定位的项目保留待查。

建议交付 `issue_ledger.csv` 和逐问题结构视图，先让“哪里不对”可以被另一人复查。现有记录清单只是 R0 的输入准备，问题定位尚未完成。

### R1：先审计现有结构链，不重新建模

按下面顺序逐步比较，每步明确允许改变的内容：

| 阶段 | 现有文件/入口 | 该步要回答的问题 |
|---|---|---|
| 原始实验模板 | `2026-10-10_peptide_samples/raw/mdm2_3EQS.pdb` | 哪些原子被观测，哪些缺失；样本序列、链和构建体是否匹配 |
| 清理与补末端 | `inputs/modeller_v2/{PRO,GLN}/` 的模板、起点与 selection记录 | 删除/altloc规则是否按协议；补建时观测骨架有没有非预期改变 |
| 变体重原子 | `inputs/modeller_v21/<样本>/heavy_v2m1.pdb` 等 | 序列和突变位点是否正确；允许变化的侧链之外是否有非预期改变 |
| reduce 加氢 | 同目录 `reduced_v2m1.pdb` 等 | 重原子对应、His/端基与氢原子名是否匹配既定化学 |
| finalize / prepared | `start_v21m1.pdb`、`prepared/<样本>/<model>/complex_dry.pdb` 与记录 | 命名、原子顺序、连接/参数与坐标是否一致；重查历史失败位置 |
| 两段最小化 | `md/<样本>/<model>/setup/minimized_state.xml`、`setup_record.json` | 约束释放前后具体几何怎样变；受力最大的原子在哪里，是否随修正消失 |
| 平衡和已有生产 | 各副本 status 所列平衡/生产文件；已有结构诊断 | 是 setup 已错、平衡阶段变化，还是后续真实构象改变 |

比较原则：

1. 以序列/残基/原子语义映射为主；对明确的对称等价原子单列允许的置换，不用不同阶段的行号硬对坐标。
2. 所有几何比较注明单位并统一到 Å。受体对齐后分别比较肽的实验可见1–11位、补建12位、突变侧链及受体补建A25；不把一个“全肽RMSD”包办这些问题。
3. 对 PMI，实验可见部分有直接坐标参考；对变体，共用骨架部分和改变侧链分别报告。对B12只报告模型间差异与运动，3EQS没有该位置的实验坐标。
4. 几何合理性沿用既有明确的 C1–C4 检查及原始连续数值。本计划不增加RMSD、接触率、局部力或“保持晶体”的新硬阈值。
5. 最大局部力、最小化退出条件与实际键角分别记录，不把它们混成同一个量。约束下结构稳定的记录需与完全撤约束后的结果分开。

建议交付：`stage_atom_map.csv`、`stage_geometry.csv`、受体对齐结构视图，以及一页 `structure_diagnosis.md`。一页结论至少写清首次变化阶段、受影响原子、参照依据和仍未定位之处。

完成6个代表的诊断后，按同一映射与检查口径核对剩余10个模型，确定问题影响范围；不直接把代表结论外推到全批。

### R2：按具体原因修复，确定重做范围

| R0/R1 查到的情况 | 复用什么 | 需要重做什么 |
|---|---|---|
| 展示/PBC/对齐或导出诊断错误，原始分子输入正确 | 原始输入、拓扑、轨迹及可核对的评分 | 有问题的导出/诊断与相关图表 |
| 只有分析时间列错 | 原轨迹与按已核实帧身份计算的结果 | 时间映射/相关时间窗口分析；修正前核对保存间隔和 chunk顺序 |
| 重建、加氢或参数化已引入硬错误 | 对应错误之前的可追溯产物 | 受影响样本/model的准备、setup、MD和评分；不把新拓扑配旧轨迹 |
| prepared正确，setup或约束释放引入错误 | 已核实的prepared输入 | 相关setup及其下游；先查出几何变化发生的步骤 |
| 只有未观测端部运动较大，核心几何正常 | 已有数据与端部不确定性记录 | 先完成分区诊断，不自动追加计算 |
| 无硬错误，但合理起点间核心姿态差异大 | 原始记录和所有诊断结果 | 先补结构证据/有限模型对照；新长MD预算后定 |

修复优先使用已有 MODELLER/reduce 的正确输入和调用，不恢复叠加旧手性补丁的路线。确有工具能力缺口时，先写清具体缺口、成熟工具候选及其对照用途，再选择；本计划未指定安装新预测器或对接平台。

如需重新准备和短松弛，建议仍先用上述3样本×2模型，固定对照输入和一次要区分的因素。运行规模、节点和时间以定位后的最小问题为准；不预先安排全8条×20 ns重跑。

### R3：解释结合姿态，确定哪些模型可用于当前问题

修复几何错误后仍需说明变体复合物依据：

- 优先核实已有同系列论文/PDB是否包含对应变体复合物，逐条对齐序列、修饰、端基和受体构建体。存在对应结构时优先作为独立几何参照。
- 模板模型可以作为条件性输入，但要明确哪些骨架/接触继承模板、哪些由建模产生；缺少各变体晶体结构本身不自动判无效。
- 若观察到需要明显骨架重排、多个互不兼容姿态或强起点依赖，先做有问题指向的少量结构对照。两个仅末端不同的起点不当作已探索全部结合模式。
- 短松弛可检查去碰撞和约束释放后的行为；结合态MD中是否仍靠近受体、单个预测置信度或PBSA分数不独立决定哪个姿态是真实结构。
- 若相近序列模板路线仍缺合理依据，记录该系列的限制，在已有候选清单中审计结构证据更齐的案例。换系列依据结构和测量质量，不依据哪个实验排序更好；MDMX与原序列家族的相关性保留说明。

建议交付 `model_use_decisions.csv`：逐样本/model写 `继续使用并注明假设 / 受影响阶段需重做 / 仅作诊断 / 姿态问题待解决`，每项链接具体证据。这张表是人工审阅结论，不新增自动拒跑规则。

### R4：结构解释清楚后，接回数值与实验评价

沿原计划补：同帧网格/旋转平移敏感性、匹配的 Amber PB/GB、最小化起点和简单接触/尺寸等基线，再做固定统计口径的实验比较。

先写明主要终点、方向、起点/副本/时间块的重采样单位以及实际候选集合。全部8条与双突变子组分开报告，未知实验误差不补造。旧轨迹是否可复用由R2/R3的证据和用途决定，不因耗费过计算就默认有效，也不因本次提出结构疑问就整批删除。
