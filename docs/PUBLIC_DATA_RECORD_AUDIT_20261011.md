## 1. 处理结论

1. Bcl-xL 两个 DOI 归到一个论文身份，但暂不把全部测量合成 22 个确定标签。原文方法和表格仍需核实，数值冲突保留。
2. MDMX 不按“超出某个 ITC 范围”删值。按原文表头、脚注和方法拆分 SPR Kd、FP Ki、ITC Kd，正式标签由原文重建。
3. 九个系列仍是候选清单；其中七个是独立验证候选，尚未证明它们彼此无重复或全部可用。验证划分需检查原始实验、样本和序列家族重叠。

## 2. Bcl-xL：论文身份可以统一，测量还不能直接合并

### 2.1 已核实

出版方和 RCSB 将 Petros 等 2000 年的 *Protein Science* 9:2528–2534 关联到 `10.1110/ps.9.12.2528`；PDBj 的同一 1G5J、同一标题及 PMID 11206074 关联到 `10.1017/S096183680000331X`。本批记录采用统一 `paper_id=PMID:11206074`，并保留两个 DOI 别名。[出版方](https://onlinelibrary.wiley.com/doi/10.1110/ps.9.12.2528)、[RCSB](https://www.rcsb.org/structure/1G5J)、[PDBj](https://pdbj.org/mine/summary/1g5j)

当前库存重新统计：

- 两个 DOI 分别有 22 条库标 FP、70 条库标 BLI，合计 92 条记录。
- 两边都覆盖同样 22 种序列。FP 的 22 条中，21 条能在另一组找到相同序列和相同解析数值。
- 全部 92 条共有 28 个候选重复簇；簇依据序列、库内受体序列、修饰/末端、指标、关系与解析数值确定，测定字段因冲突单独保留。**重复簇不是已核实的独立测量。**
- 有 6 种序列在库存中出现多个数值。FP 与另一组唯一未匹配的一条为 `PPIRE19058`：库内 1.2 nM，而另一 DOI 下同序列的三条均为 0.2 nM。不能任选或平均。
- 22 种序列包括 10 种 25 肽、12 种 16 肽，结构/长度不是一个统一输入类型。

### 2.2 未解决项及处理

本轮能读取论文摘要和书目信息，正文为 PDF，尚未成功读取其完整方法和数据表。参考文献里出现 FP 不足以证明每条数据都由 FP 得到；因此 `curated_assay` 留空，所有 Bcl-xL 库标签暂缓正式使用。不把库标 BLI 全量改成 FP。

下一步取得并审阅该原文 PDF，逐条定位表/行、实验方法、受体构建体、末端、数值和单位；确认哪些库记录是同一原始测量的多次收录，哪些是不同实验或抄录冲突。冲突不能直接取平均，也不能因 DOI 别名就覆盖原始记录。

还需核对 16 肽属于哪一来源家族、哪些数值沿用其他论文。1G5J 的摘要说明其结构对应 Bad 25 肽，不能把它当作每一条 16 肽的直接实验结构。[原文摘要](https://pmc.ncbi.nlm.nih.gov/articles/PMC2144516/)

## 3. MDMX：原文标签已经重建，库内“ITC 组”需拆开

### 3.1 已核实的来源依据

从保留的 Li 2021 原文 HTML 重新解析 Table 2、Table 3，并检查表标题、Table 3 脚注 a 和方法 §2.4：Table 2 的 Kd 为 SPR、Ki 为 FP；Table 3 的 PMI-M3 Kd 有 ITC 脚注，其余本批 Kd 属于竞争 SPR。不能按数值大小判定测定类型。[Li 2021 原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC8463443/)

Table 2 与 Table 3 重复出现的 PMI-L10A 保留两个出处、只计一次测量。**就本批 Table 2/3 所覆盖系列**，MDMX 得到 55 条原文标签：

| 清单 | 数量 | 用途 |
|---|---:|---|
| 竞争 SPR Kd | 27 条 / 27 种序列 | 同测定的亲和力排序；仍需结构/化学审计。 |
| FP Ki | 27 条 / 27 种序列 | 单独分析，不能当 Kd 或与 SPR 混合。 |
| ITC Kd | 1 条：PMI-M3 | 单列；不能单独构成 ITC 多样本排名组。 |

重新提取与历史 `mdm2_mdmx_primary_measurements.csv` 的 MDMX 点逐项一致。不同表头和脚注也独立核对了测定归属。

### 3.2 具体冲突

| 库记录 | 库内内容 | 原文核对结果 | 处理 |
|---|---|---|---|
| `PPIRE10659` / PMI-M2 | 2.3 pM、ITC | Table 3 为 2.3 ± 0.6 **nM**、SPR Kd | 单位和测定标签均冲突；原文重建标签。 |
| `PPIRE10663` / PMI-M3 | 10.7 pM、ITC | Table 3 为 10.7 ± 2.4 pM、ITC Kd | 保留为原文报告结果，单列，不按范围删掉。 |
| `PPIRE10831` / PMI | 8.2 nM、ITC | Table 3 为 8.2 ± 1.4 nM、SPR Kd | 数值相符，但测定标签冲突。 |
| `PPIRE00659` / 同序列样本 | 20,000 µM（20 mM）、ITC Kd | Table 2 同序列有 SPR Kd 244 ± 13 nM、FP Ki 120 ± 3 nM | 不能把 20 mM 标签用于排名；不能据序列猜库行原本指哪条测量。使用独立原文清单。 |
| `PPIRE00640`、`PPIRE10665` / PMI-M3 | Ki 34 nM、Ki 5.8 pM | 原文 Table 2/3 没有该序列可对应的 Ki 定量点 | 隔离待查；不把它们改成 Kd。 |

作者对超紧结合 ITC 的精度有明确保留，并说明图中选取了一个较低 SD 的代表性运行。因此保留“作者报告的 10.7 pM”，不把它提升成已充分验证的精确真值。此前“远超 ITC 能测范围”的一刀切表述应撤回：是否可信必须结合原始测量和误差，而非设一个通用数值区间。

### 3.3 库记录审计范围

该论文、MDM4/MDMX 在当前库存共 66 条记录。其中库标 ITC 有 33 条；此前 §4.4 的 15 条是其中解析为 Kd 的子集，另外 18 条是 Ki。按原文核对入口对应，33 条分别落到 14 条 SPR Kd、18 条 FP Ki、1 条 ITC Kd。这里的对应依赖序列与库内指标，**不是证明损坏的数据库行就是该原始实验的唯一来源**；正式使用原文重建点。

全 66 条审计发现 56 条数值/单位冲突、48 条测定冲突、2 条无可对应指标点；这些标记可重叠，不能相加成坏记录总数。仅 4 条测量标签完全匹配，不代表其结构或实验化学已经通过审计。
