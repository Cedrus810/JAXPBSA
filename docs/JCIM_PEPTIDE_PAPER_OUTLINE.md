# JAXPBSA 多肽论文框架 v0.1

日期：2026-10-03。状态：研究问题、论文组织与实验设计初稿；尚未证明多肽排序有效，也未开展新多肽的实验验证。用户已确认本阶段使用公开亲和力/结合数据。

## 1. 建议定位

把主应用聚焦于**多肽结合候选的快速系综重评分与优先级排序**，以 JAXPBSA 的 GPU MM/PBSA 和 OpenMM 在线分析为技术基础。

核心问题：在固定计算预算下，JAXPBSA 能否提供可靠的物理评分，帮助研究者从多肽候选中选出更值得实验验证的序列？

需要分别回答三件事：数值实现是否可靠、候选评分是否有实验相关性、完整工作流是否因此更有效。求解器加速只回答其中一部分。

暂定标题：

> JAXPBSA: GPU-Accelerated Ensemble Rescoring for Peptide Binder Prioritization

中文工作标题：JAXPBSA：面向多肽结合候选筛选的 GPU 系综重评分。

“physics-guided peptide design”可以作为研究方向。标题和摘要是否提升到“design”，取决于是否形成新的候选生成—筛选—实验验证闭环。公开实验数据上的重评分足以研究筛选价值，但不能声称发现了新的有效多肽。

**本阶段确定的范围**：公开实验数据上的回顾性、参数冻结的候选优先级验证。主框架不依赖新增湿实验；新多肽实验作为未来升级路径保留。评价重点是靶点内排序、top-k 富集及完整计算成本。

这会收窄此前审查中的通用软件定位：主应用的新增体系优先选择不同类型的蛋白–多肽，而非优先扩展小分子。数值正确性与现有 GPU 工具对照仍需要保留。

## 2. 现有基础与证据边界

| 内容 | 已有基础 | 本论文仍缺的证据 |
|---|---|---|
| MM/PBSA 实现 | MM cross、PB、SASA；Amber 分项对照 | 多序列、多构象上的可靠性及失败帧验收 |
| GPU 性能 | 多卡与阶段计时、编译与稳态分离 | 完整候选库的端到端成本，序列改变导致的编译与定尺成本 |
| 在线分析 | OpenMM reporter、pilot 定尺、边界与收敛标记 | 对候选筛选有什么可测量的价值 |
| 多肽体系 | MDM2–p53（1YCR）、Src SH2–磷酸化肽（S4） | 实验标注的变体或设计候选排序 |
| 高斯模型/NLPB | 球模型、25 单体蛋白对照 | 多肽排序的独立验证；不预设其提升 |

已有两条野生型/参考肽轨迹属于基础测试，不是多肽设计验证。当前 MM/PBSA 不包含熵项，应称能量估计或评分；候选间差值写为 relative MM/PBSA score，不能默认等于实验 ΔΔG。

## 3. 文献中的具体机会

MM/PBSA 已用于蛋白–多肽评分，dMM-PBSA 研究曾比较多种评分函数。因此“把 PBSA 用于多肽”本身不是新主张；需要证明本工具带来的速度、在线使用或筛选价值。[dMM-PBSA 原始研究](https://www.frontiersin.org/journals/molecular-biosciences/articles/10.3389/fmolb.2016.00046/full)

一个直接可考察的数据来源是 BindCraft 多肽实验研究：其 MDM2 案例使用 1YCR，报告候选的实验结合结果，并包含 WDR5 等目标。MDM2 上有 15 个成功纯化并检测的候选，其中 7 个显示明确结合。它提供了在生成模型之后增加物理重评分的具体应用背景；原始候选结构是否完整公开、标签如何定义，还需核对补充资料。[BindCraft 多肽研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12723675/)

MDM2/PMI 的组合丙氨酸扫描研究也可作为变体数据来源。当前仅确认其研究范围；具体序列、定量亲和力、结构与测量条件需逐项审计后再纳入。[组合扫描原始研究](https://www.nature.com/articles/s42004-022-00737-w)

已有 s_mmpbsa 也展示了多肽相关应用，说明软件创新必须落在可验证的工作流优势上。[s_mmpbsa 原始研究](https://doi.org/10.3390/molecules31101683)

## 4. 两层应用：先变体，再设计候选

### A. 同一骨架的多肽变体

优先从 MDM2–p53 或 PMI 的实验变体开始。相近长度与化学类型便于控制构象、净电荷、末端及参数差异。必须同时包含强结合与弱结合变体，不能只选符合预期的热点突变。

先挑 6–8 个数据可对齐的候选做协议试验，再形成约 20–40 个候选的验证集；这是工作量规划，不是投稿门槛或已取得的数据。实际数量取决于公开数据质量。

每条序列都需重新准备侧链、氢、电荷、半径、索引与力场系统，并分别采样。用野生型轨迹换侧链可作为便宜基线，但不能替代变体的系综。实验测量需核对受体构建体、末端修饰、pH、盐浓度和温度。

特别注意：当前 `prep_1ycr.py` 给受体与 p53 肽均加 ACE/NME 帽，以模拟完整蛋白片段；这不保证与某篇实验中的合成肽末端一致。公开数据的序列/修饰必须控制输入，不能直接沿用现有 canonical 制备作为全部变体的实验模型。

### B. 生成工具的候选重排序

优先审计上述 BindCraft MDM2 候选。用可取得的原始预测结构或预先固定的重建流程建立输入，比较原始模型排序、MD+MM/GBSA、MD+JAXPBSA。

只在已检测且标签明确的候选上评价实验命中表现。未经检测的设计不能标作非结合者；纯化失败不能自动标为结合阴性；不明确的 BLI 曲线也不能直接换算成 Kd。该集合规模较小，需报告不确定性，并用第二靶点或独立变体集交叉检查。

该研究已确认结合的 MDM2 候选报告的 Kd 约为 65–165 nM，跨度较窄。其强项可能是检测候选的分类/富集检验，是否适合细粒度亲和力排序需结合测量误差判断；定量变体集应另行选择。[原始测量说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC12723675/)

第二靶点按数据质量选：Src SH2 的磷酸化肽可利用现有 S4 作为数值和强电荷测试；WDR5 候选可能更适合独立设计验证。两者尚未完成数据审计，不预先指定哪个一定进入主文。

### 若能开展新实验

冻结评分协议后生成新候选，预先选择约 6–12 条进行测试：包括 JAXPBSA 高分组、基线高分组、两种方法分歧组及参考肽。相同实验条件下测结合与必要的位点竞争，公开全部测试结果。

规模仍由资源决定。仅测本方法最高分的少量候选，难以证明增量筛选价值；需要对照选择策略。细胞效应、稳定性与递送属于另外的实验主张，不能由结合评分推断。

## 5. 预先固定的实验协议

### 数值验证

- 在同一批快照上分别加密 C/R 和配体网格，考察 score 和候选排序的变化。
- 检查亚格点平移、刚体旋转、边界余量、求解容差和失败状态。
- Amber 或可获得的 GPU PB 实现用于核查数值；模型和参数不一致时，明确区分模型差异与实现误差。
- 不能以提高分数/亲和力相关性为理由，在测试集上调介电常数、半径、σ 或电荷权重。

### 系综采样与统计

第一版用统一的平衡流程和固定预算 MD。每条候选先安排至少三条独立 replica，长度由试验阶段的构象和评分统计决定；不预设 10 ns 便足够。

报告 replica 间变化、分块均值、相关性和置信区间。置信区间按 replica 或时间块估计，不能把高频保存的帧都当独立样本。对构象与预组织差异较大的候选，增加游离多肽系综诊断；结合态能量评分没有自动包含构象熵和重组自由能。

### 三类指标

| 问题 | 主指标 | 补充检查 |
|---|---|---|
| 数值是否可靠 | 逐帧绝对误差、网格加密后的相对分数变化、排序稳定性 | 求解失败率、边界失败率 |
| 能否选出候选 | 同一靶点内 Spearman/Kendall、top-k 命中/富集、序列选择重合度 | 分块/replica 不确定性；有标签时 PR/ROC |
| 计算是否更划算 | 固定 GPU 小时下完成候选数及实验支持的筛选表现 | MD、准备、编译、分析、I/O 时间；峰值显存 |

Kd 定量结果可换算为相同条件下的 pKd 或实验相对自由能；IC50 不直接当成 Kd。亲和力未定量的候选用于分类或删失数据分析。跨靶点不直接汇总原始 MM/PBSA 分数排序。

### 基线与公平比较

至少包括：原始设计/结构评分、一个常用 MM/GBSA 流程、CPU Amber MM/PBSA。硬件性能再增加一种可获得的 GPU PB 工具。建议加入长度、净电荷和简单接触指标作为诊断基线，检查物理评分是否只是依赖这些特征。

比较 JAXPBSA 与 Amber 实现时共享快照；比较 MD 重评分与原始模型筛选时，报告额外 MD 的成本。对于“固定预算改善筛选”的主张，统一总预算与候选池。序列变化引起的 shape 改变、重新编译和 pilot 成本都计入，不能只用同一体系重复帧的 ms/帧外推候选库吞吐。

在线阶段先验证同帧在线/离线一致及 MD 开销。观察到实时评分不等于安全的早停策略；自适应停止若成为贡献，需要在保留集上评价误删有效候选的概率和预算收益。

## 6. 需要增加的软件能力

### 第一批

1. **候选清单与准备入口**：读取序列、复合物/受体来源、末端修饰、目标位点；保存参数来源、原子映射、输入哈希。
2. **多候选任务运行器**：每候选/replica 独立输出，可断点恢复，记录失败及重跑原因。
3. **排名与统计报告**：各分项、score、有效帧数、采样区间、数值 flags、replica 不确定性；支持相对参考肽评分。
4. **验证与成本汇总**：已有验证脚本增加收敛/边界验收，完整记录准备—编译—MD—评分的墙钟成本。

最初支持普通线性 L-氨基酸多肽及明确列出的现有修饰。新环肽、订书钉、D-氨基酸或非天然残基需要单独的参数化与验证，再扩展支持。

### 证据出现后再决定

残基级 MM/接触解释可帮助理解突变；总 MM/PBSA 分项已经有基础。PB 残基分解若新增，需要定义方法和验证，不能把全分数假定为逐残基可加。

生成器先作为可替换的上游输入；不需要为第一版自建生成模型。NLPB、gaussian_gap 或熵修正是否进入主线，由独立排序实验决定。JAX 实现也不自动意味着整个离散 PBSA 流程可用于可微序列设计。

## 8. 摘要骨架（待填结果）

1. 问题：多肽候选的优先级排序需要考虑构象与溶剂效应，同时控制系综分析成本。
2. 方法：介绍 JAXPBSA 的 GPU MM/PBSA、OpenMM 在线接口和多候选分析流程。
3. 验证：在 [靶点/候选数] 上报告 [数值误差]、[独立实验排序指标] 和 [完整工作流成本]。
4. 意义：按实际结果说明其支持的筛选任务和适用范围。

任何“提高命中率”“发现新多肽”“准确预测亲和力”的句子，都等对应证据后填写。性能提升可以独立成立，但不能推导出亲和力预测改善。

## 9. 先做的四个工作包

| 工作包 | 交付物 | 继续扩大投入的依据 |
|---|---|---|
| WP1 数据审计 | 实验标注清单、序列/修饰、构建体、条件、结构来源、出处 | 输入与实验可对齐，包含有效的弱结合/阴性标签 |
| WP2 小规模试验 | 6–8 候选 × 3 replica；网格敏感性、成本与初步排序 | 数值误差与采样变化不淹没有意义的候选差异 |
| WP3 独立验证 | 冻结参数的候选集与第二靶点、统一基线和完整成本 | 在独立数据上验证实际排序/筛选价值 |
| WP4 公共数据复现交付 | 可公开的数据清单、允许再分发的输入/结果、冻结环境和一键复现入口 | 独立读者可重现排序、误差与成本 |

新设计—湿实验闭环暂不进入本阶段的必做工作包。

如果小规模试验只恢复严重破坏热点的突变，却无法区分合理候选，不宜宣称精细亲和力排序。如果加速分析后端到端时间仍由 MD 主导，应据实报告收益并研究提高统计分辨率的价值。若评分不能改善实验筛选，仍可以围绕可靠快速的软件分析形成更窄的 Application Note。
